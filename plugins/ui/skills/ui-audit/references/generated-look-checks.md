# Generated-look checks

Twenty habits that make a page read as machine-made. Run these on every marketing page, landing page and hero, and on any screen the user says looks generated or generic. The fix for each one is in the `ui-craft` skill's `references/generated-look.md`.

## Decoration

- [ ] No sparkle icon on a feature, a button or the word "AI".
- [ ] No pulsing dot beside a status or a label.
- [ ] No blurred colour glow behind the hero.
- [ ] No dithered or grain texture laid over images and gradients.
- [ ] No coloured left border on cards, notes or quotes.
- [ ] The display typeface has a reason from the product. Instrument Serif with no reason is a finding.
- [ ] The background colour has a reason from the product. Cream or warm off-white with no reason is a finding.

## Layout

- [ ] Arrows only on controls that move the user forward or back, never on every button and link.
- [ ] No dot between words in every line of meta text.
- [ ] An eyebrow label only where it adds a fact the heading lacks.
- [ ] A pill above the headline only when it carries news with a date and a link.
- [ ] Cards only for items the user can open, move or compare.
- [ ] No row of three icon cards. The number of points is the real number, and each one shows the product.
- [ ] Numbers only on steps the user does in order.
- [ ] No fade or slide on every section as it scrolls into view.

## Words

- [ ] No single word of the headline in italic, or in another colour or weight.
- [ ] No "quiet" as praise.
- [ ] No "real" as a claim.
- [ ] Every statistic, quote and customer name has a source the owner confirmed.
- [ ] No run of two-word sentences.

## Report

| Finding | Severity |
|---|---|
| A statistic, quote or customer name with no source | Major. It misleads users. Critical when it is the page's main claim |
| Three or more other tells on one page | One Minor finding that lists them all |
| One or two other tells | Report each only where it has no reason from the product, as Minor |

- When you cannot tell whether a figure is sourced, list it under "not checked" and ask the user.
- A tell that the brief or the project's design system asks for is not a finding.
