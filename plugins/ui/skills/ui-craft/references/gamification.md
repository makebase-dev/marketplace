# Light gamification that encourages

Owner's rule: "the goal is to encourage, not put a new system for the user to learn."

## Simplicity budget

- Every game element is a side effect of the one action users already take (marking an exercise). No currency, levels, shop, leagues, tutorial.
- At most three things, visible at a glance: a forgiving streak, progress rings per topic, a handful (about five) of milestones. Tools (exam timer, countdown) are not games.
- Plain words and real units ("12 study days", "7 of 12 exercises"); no XP or points — a second number system with no meaning for the goal.
- Home shows at most two game numbers; other screens at most one; larger screens never show more than phones.
- If a mechanic needs a help screen, cut it.

## Mechanics that work

| Mechanic | How it avoids pressure |
|---|---|
| Streak with built-in rest days (2 in 7) | Rest is built in, not bought; a broken streak shows "longest" and "days this month", which never go down (slack raises persistence: Sharif & Shu) |
| Daily goal the user picks (1/3/5) | Missing it costs nothing |
| Progress rings that can go down and back up | Words describe practice, not ability; a drop shows its reason (Khan Academy users were confused by unexplained drops) |
| A few milestones tied to learning actions ("Honest mark" for a first wrong answer, "Comeback" for a fixed mistake) | Rare, never revoked, shown only when earned, no grid of locked slots |
| Exam timer | Calm bar or text-only or hidden (about 20 % of students report timer anxiety); notices at 15 and 5 minutes; no seconds |
| Countdown | Only official dates; explicit "not announced" and "cancelled" states |
| Share card | User picks what goes on it; preview matches toggles; nothing uploaded |

## Never

Leaderboards and leagues (embarrass the bottom), hearts or lives, paid or earned streak freezes, guilt notifications, sad mascots, random rewards, a countdown to losing the streak, red "wrong" bars on progress pages, celebrating time on site.
