# The generated look

Twenty habits that make a page read as machine-made. Each one is a default: the page has it because nobody chose otherwise.

- Use one only when the brief asks for it, or when you can give the reason this product needs it.
- One of them alone is a choice. Three or more on one page read as a template: remove them until the remaining ones have a reason.

## Decoration

| Tell | Instead |
|---|---|
| A sparkle icon on a feature, a button or the word "AI" | Name what the feature does. Use an icon only where `icons.md` allows one |
| A pulsing green dot beside a status or a label | Show a status only when it is live data, as a word with a still mark. Nothing loops (`motion.md`) |
| A blurred colour glow behind the hero | Take depth from the product itself: a screenshot, a photo, or a flat surface one lightness step up |
| A dithered or grain texture laid over images and gradients | Use the image as it is. Add texture only when it comes from the product's world |
| A coloured left border on a card, a note or a quote | Mark a callout with its heading and its place on the page. Keep an edge marker for the selected state |
| Instrument Serif, or another display serif chosen because it is in fashion | Choose the typeface from the product's world, and say why it fits |
| A cream or warm off-white background by default | Take the background from the product's colour world. Plain white is a valid choice |

## Layout

| Tell | Instead |
|---|---|
| An arrow on every button and link | Write a label that says where it goes. Keep an arrow for a control that moves the user forward or back |
| A dot between words in every line of meta text ("Design · 4 min · 2026") | Put each fact where it belongs, or write a sentence. Keep a separator for one short line of facts of the same kind |
| An eyebrow label above every heading | Write a heading that needs no label. Keep an eyebrow where it adds a fact the heading lacks |
| A pill or badge above the headline ("New", "Now in beta") | Remove it, unless it carries news with a date and a link |
| Every block inside a card | Use a card only for an item the user can open, move or compare. Separate the rest with space and headings |
| Three icon cards in a row | Use the real number of points. Show each one with what it looks like in the product: a screenshot, an example or a figure |
| Sections numbered 01, 02, 03 when the content is not a sequence | Number only steps the user does in order |
| Every section fading or sliding in on scroll | Show the content at once. `motion.md` lists scroll-triggered reveals among the motion to leave out |

## Words

| Tell | Instead |
|---|---|
| One word of the headline in italic, or in another colour or weight | Emphasise the whole line, or nothing |
| "Quiet" as praise ("quiet confidence", "quietly powerful") | Say what the product does, with the number or the example |
| "Real" as a claim ("real results", "built for real teams") | Give the result, and name who uses it |
| A statistic nobody measured ("10x faster", "98% of teams") | Use only a figure the owner can source, with its unit and date. With no figure, describe the behaviour, and ask the owner for a number |
| Two-word sentences in a row ("No fluff. Just results.") | Write one whole sentence that states the benefit |

## Check before calling a page done

1. Count the tells on each page.
2. For each one, write the reason this product needs it. Remove each one that has no reason.
3. Ask the owner about every figure, quote and customer name you did not get from them. Never ship an invented one.
